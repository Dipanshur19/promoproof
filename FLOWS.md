# PromoProof QA inventory

## Main flows and signoff claims

- Empty state: no invented metrics, no confidential bundled scripts.
- Synthetic demo → rules run → shortlist, intervals, evidence, quality flags.
- Uploaded full ZIP → all episodes scanned, measured event count, scene warning preserved.
- Search, empty search and reset; audience and continuous/composite filtering.
- Proposal selection → story, source, quality tabs.
- Notes → accept/reject → summary and exported state.
- Continuity → record scoped identity decisions without claiming automated merges.
- Audit → usage, fingerprints, coverage, unselected episodes.
- JSON / spreadsheet-safe CSV / raw ZIP exports.
- Settings → model, provider, AI, consent, composite toggle; missing provider explicit.
- New upload does not erase existing results until a successful run.
- Malformed source and unsafe ZIP: visible errors, no partial parse.
- Cancel: previous results preserved.
- Clear: in-page confirmation.

## Visual checks

Desktop 1440px and mobile 375px: empty, shortlist, source, quality, continuity, audit, settings. Check overflow, contrast, controls and console.

## Hosted preview

Fresh context: load, synthetic run, tabs, filters, navigation, settings, JSON/CSV/ZIP downloads.

## Exploratory cases

No filter matches; malformed TXT; no model key; source-scene mismatch; repeated footage; invented evidence; simultaneous action and sound.
